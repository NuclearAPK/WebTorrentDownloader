# Changelog

## [1.0.8] - 2026-04-07

### Исправлено
- Выбранные файлы теперь видны в списке скачанных файлов во время загрузки
- Скрываются только невыбранные файлы (sparse-заглушки), а не все файлы активных торрентов
- Подтверждено: опция `deselect: true` корректно работает — до выбора файлов данные не скачиваются (файлы на диске содержат нули)

## [1.0.7] - 2026-04-07

### Исправлено
- Размер торрента пересчитывается по выбранным файлам (вместо полного размера торрента)
- Прогресс и скачанные байты учитывают только выбранные файлы
- Файлы активных незавершённых торрентов (sparse-заглушки от chunk store) не отображаются в списке скачанных файлов
- Дублирование логики формирования данных торрента вынесено в общую функцию `mapTorrentData`

## [1.0.6] - 2026-04-07

### Исправлено
- Критический баг: `client.get()` в WebTorrent 2.x — async-функция, добавлен `await` во все эндпоинты (pause, resume, select-files, delete)
- Выбор файлов теперь корректно применяется и сохраняется

## [1.0.5] - 2026-04-07

### Исправлено
- Использование встроенной опции WebTorrent `deselect: true` для полного предотвращения скачивания до выбора файлов
- Состояние «Ожидание выбора файлов» — прогресс-бар и статистика скрыты до подтверждения выбора пользователем
- Однофайловые торренты начинают загрузку автоматически

## [1.0.4] - 2026-04-07

### Исправлено
- Многофайловые торренты теперь полностью приостанавливаются (pause + deselect) до выбора файлов пользователем
- После подтверждения выбора файлов торрент автоматически возобновляется
- Список файлов в окне выбора отсортирован по имени

## [1.0.3] - 2026-04-07

### Добавлено
- Отображение версии приложения в интерфейсе
- Ссылка на GitHub-репозиторий в футере

## [1.0.2] - 2026-04-07

### Добавлено
- Пауза и возобновление загрузки торрентов (кнопки "Пауза" / "Продолжить")
- Визуальная индикация приостановленных торрентов (оранжевый прогресс-бар, бейдж "На паузе")
- Выбор файлов для скачивания в многофайловых торрентах
- Автоматическое модальное окно выбора файлов при добавлении многофайлового торрента
- Кнопка "Файлы" для повторного изменения выбора файлов
- Отображение размера каждого файла в списке файлов торрента
- Пометка "Пропущен" для невыбранных файлов
- API: `POST /api/torrents/:infoHash/pause` — пауза торрента
- API: `POST /api/torrents/:infoHash/resume` — возобновление торрента
- API: `POST /api/torrents/:infoHash/select-files` — выбор файлов для скачивания

### Исправлено
- Многофайловые торренты больше не начинают загрузку до выбора файлов пользователем

## [1.0.1] - 2026-04-06

### Исправлено
- Обработка ошибок SSDP-сокетов
- Выбор IP-адреса DLNA-сервера — приоритет реальных сетевых адаптеров

### Добавлено
- Настройка `torrent.port` в конфигурации

## [1.0.0] - 2026-04-06

### Добавлено
- Регистрация и авторизация пользователей (JWT)
- Скачивание торрентов по магнет-ссылкам и .torrent файлам
- Отображение прогресса в реальном времени (SSE)
- Управление скачанными файлами
- Настраиваемый каталог загрузки
- DLNA/UPnP — обнаружение устройств и трансляция медиа
- DLNA Media Server
- HTTP-стриминг с Range requests
- Транскодирование видео на лету (ffmpeg)
