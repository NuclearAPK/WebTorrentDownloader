# Changelog

## [1.0.3] - 2026-04-07

### Добавлено
- Отображение версии приложения в интерфейсе
- Ссылка на GitHub-репозиторий в футере

## [1.0.2] - 2026-04-07

### Добавлено
- Пауза и возобновление загрузки торрентов (кнопки "Пауза" / "Продолжить")
- Визуальная индикация приостановленных торрентов (оранжевый прогресс-бар, бейдж "На паузе")
- Выбор файлов для скачивания в многофайловых торрентах
- Автоматическое модальное окно выбора файлов при добавлении многофайлового торрента
- Кнопка "Файлы" для повторного изменения выбора файлов
- Отображение размера каждого файла в списке файлов торрента
- Пометка "Пропущен" для невыбранных файлов
- API: `POST /api/torrents/:infoHash/pause` — пауза торрента
- API: `POST /api/torrents/:infoHash/resume` — возобновление торрента
- API: `POST /api/torrents/:infoHash/select-files` — выбор файлов для скачивания

### Исправлено
- Многофайловые торренты больше не начинают загрузку до выбора файлов пользователем

## [1.0.1] - 2026-04-06

### Исправлено
- Обработка ошибок SSDP-сокетов
- Выбор IP-адреса DLNA-сервера — приоритет реальных сетевых адаптеров

### Добавлено
- Настройка `torrent.port` в конфигурации

## [1.0.0] - 2026-04-06

### Добавлено
- Регистрация и авторизация пользователей (JWT)
- Скачивание торрентов по магнет-ссылкам и .torrent файлам
- Отображение прогресса в реальном времени (SSE)
- Управление скачанными файлами
- Настраиваемый каталог загрузки
- DLNA/UPnP — обнаружение устройств и трансляция медиа
- DLNA Media Server
- HTTP-стриминг с Range requests
- Транскодирование видео на лету (ffmpeg)
